# Danny's Estate

Client-ready real-estate website starter for Port Harcourt, Rivers State.

## Included
- Responsive website
- Property search/filtering
- Property detail modals
- WhatsApp enquiry links
- Phone/email contact links
- Contact enquiry form that opens WhatsApp
- Six sample property listings
- Generated property imagery in `house1.jpg`–`house4.jpg`

## Important
The property information and images are **demo/sample content**, created to demonstrate the website. Replace them with the client's verified inventory, prices, title information and photographs before publishing or advertising any property.

## Run
This version is static and can be checked immediately by opening `index.html` in a browser. Internet access is only used for the Google Fonts import and WhatsApp links; the core page works locally.
